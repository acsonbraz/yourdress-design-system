# YourDress design system

Use the `designyourdress` skill for every task that creates, redesigns, reviews, or implements YourDress UI or branded visual assets.

The repository-scoped OpenAI skill lives at `.agents/skills/designyourdress/SKILL.md`. The portable source lives at `skills/designyourdress/SKILL.md`.

Treat the skill's tokens and brand rules as the source of truth unless the user explicitly requests a deviation.
